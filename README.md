# Before we meet

An interactive meeting check with five animated slides, a time-cost calculator, a written brief, and a final choice to meet or respond asynchronously.

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

```bash
npm run build
npm start
```

## Notes

- Built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide icons.
- Answers stay in memory in the current tab; refreshing clears them.
- Copy reply creates text for the visitor to send manually. No messages or calendar invites are sent.
- Includes responsive layouts and reduced-motion support.
- Inspired by https://basecamp.com/gettingreal/07.3-meetings-are-toxic.

Live app: https://before-we-meet.sora2230.chatgpt.site
